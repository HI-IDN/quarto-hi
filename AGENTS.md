# Repository guidance

## Generic template and personal forks

- `HI-IDN/quarto-hi` is the canonical generic template.
- Personal forks may override the template with presenter names, ORCIDs, usernames, email addresses, affiliations, photos, event details, or other personal information.
- Never sync personal overrides from a fork back into `HI-IDN/quarto-hi`.
- Keep names and contact details in the generic template as neutral placeholders. Before copying changes from a personal fork, review the diff for personal metadata and replace it with generic examples.
- The bundled Quarto extension belongs under `_extensions/hi-idn/haskoli-islands/` in the generic template.
